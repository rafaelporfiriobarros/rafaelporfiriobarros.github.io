# Portfólio — Rafael Porfirio

Portfólio pessoal desenvolvido com HTML e CSS para publicação no GitHub Pages.

## Publicar

1. Crie um repositório chamado `SEU-USUARIO.github.io`.
2. Envie `index.html` e `style.css` para a raiz do repositório.
3. No GitHub, acesse **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha `main` e `/ (root)`.
6. Salve e aguarde a publicação.

## Personalização

- Troque os links `https://github.com/` pelo seu perfil/repositórios.
- Troque `https://www.linkedin.com/` pelo seu LinkedIn.
- Adicione seu currículo, imagens dos dashboards e novos projetos.
